# Магістерська дисертація у .docx

Джерело правил — `docs/diploma/rules.md` (ID `F-x.y`). Вимоги до змісту частин — `docs/diploma/thesis_rules.md`. Шаблон — `docs/diploma/templates/83561_oppm_smai_md_2026.docx`. Перед роботою прочитай `rules.md`; при розбіжностях пріоритет: шаблон → Рекомендації КПІ → ДСТУ.

## Інструменти

1. `scripts/thesis_docx.py` — клас `ThesisDoc`: відкриває шаблон, залишає титул і завдання (розділ Word №1, праве поле 15 мм) і колонтитул з номером сторінки праворуч (розділ №2), видаляє демонстраційний вміст і додає елементи з уже правильним форматуванням:
   1. `structural("ВСТУП")`, `chapter(1, "Назва")`, `section("1.1", …)`, `subsection("1.1.1", …)`, `chapter_conclusions(1)`, `appendix("А", …)`;
   2. `para(text)` (підтримує `**жирний**`, `*курсив*`, сам ставить нерозривні пробіли після «рис.», «табл.», ініціалів);
   3. `numbered_list`, `bullet_list`, `inline_list` (пунктуація за F-7.*);
   4. `figure(path, "1.1", "Назва", width_cm, legend=[…], source="22", ai_note="…")`;
   5. `table(rows, "2.1", "Назва", font_pt=12, numeric_cols={1})` — назва над таблицею, усі межі, повтор шапки;
   6. `formula(r"\LaTeX", "2.1", trailing=",")` + `where([("x", "опис"), …])` — OMML через `math2docx`, номер праворуч на табуляції 17 см;
   7. `toc()`, `references([...])`, `footnote(par, text)`, `save(path)`.
2. `scripts/check_docx.py file.docx` — автоматична перевірка: поля, A4, номер сторінки, шрифт/кегль/інтервал/відступи основного тексту, формат заголовків, порядок структурних елементів, одиничні підрозділи, преамбула і «Висновки до розділу N», підписи рисунків/таблиць, наявність і порядок посилань на рисунки/таблиці/формули/джерела, «де:» , тире й лапки, «даний/наступні», ключові слова і числа в рефераті. Вивід — нумерований список з ID правил.

Залежності: `python-docx`, `math2docx` (необов'язково, для формул). Якщо їх немає в системному Python — створи venv у scratchpad (`uv venv` + `uv pip install python-docx math2docx`).

## Генерація нового документа

1. Створи скрипт збирання (у scratchpad або поруч із роботою), імпортуй `ThesisDoc` з `.claude/skills/thesis-docx/scripts`.
2. Порядок викликів — строго за F-3.1: `РЕФЕРАТ` → `ABSTRACT` → `toc()` → (перелік скорочень) → `ВСТУП` → розділи → `ВИСНОВКИ` → `references()` → додатки. Декларацію (форма `docs/diploma/templates/Декларація_АД+ШІ_КПІ.docx`) вставляють після титулу вручну у Word або окремим аркушем.
3. У кожному розділі: `chapter()` → абзац-преамбула → підрозділи (≥ 2) → `chapter_conclusions()` → абзац тексту. Не завершуй підрозділ рисунком/таблицею — після них завжди абзац (F-3.6).
4. Посилання на рисунок/таблицю пиши в тексті **до** виклику `figure()`/`table()`; нумерація `N.M` в межах розділу; формули нумеруй лише ті, на які посилаєшся.
5. Перелік посилань — у порядку першої згадки, за ДСТУ 8302:2015 (зразки — F-12.7).
6. Матеріали, створені ШІ (рівень 3), — `ai_note` у `figure()` або `footnote()` (F-16.3).
7. Збережи, запусти `check_docx.py`, виправ усі порушення, повтори.
8. Зміст (поле TOC) оновлюється при відкритті у Word (F9 / «Оновити поле»). Якщо є LibreOffice — конвертуй у PDF (`soffice --headless --convert-to pdf`) і переглянь верстку: висячі заголовки, розриви таблиць («Продовження таблиці N.M» додається вручну), порожні сторінки.

## Редагування / перевірка наявного .docx

1. Запусти `check_docx.py` і покажи користувачу нумерований список порушень.
2. Для правок використовуй python-docx (або skill `anthropic-skills:docx` для складних змін XML / tracked changes). Пряме форматування став явно: TNR 14, 1,5, відступ 1,25 см, за шириною, 0 pt до/після; стиль `Normal` шаблону має 13 pt / 1,1 — не покладайся на нього.
3. Не змінюй розділ №1 (титул, завдання) крім заповнення полів; не чіпай колонтитули.
4. Після правок — повторна перевірка.

## Що скрипт не перевіряє (дивись у PDF)

1. Заголовок останнім рядком сторінки, кожен структурний елемент з нової сторінки (F-3.2, F-5.9).
2. Розміщення рисунка/таблиці відносно посилання (поруч чи на наступній сторінці).
3. «Продовження/Кінець таблиці N.M» на розривах.
4. Відповідність змісту номерам сторінок, загальний обсяг (F-1.6).
5. Коректність бібліографічних описів за ДСТУ 8302 (перевіряй вручну за F-12.7).
